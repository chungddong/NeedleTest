학습에 쓰지 않은, 사람이 직접 쓴 신고 문장 32개입니다. 각 문장마다 정답, 원본 모델(공식 2비트), 파인튜닝 v2(20레이어)의 출력을 나란히 놓았습니다. 틀린 항목은 빨간 테두리로 표시했습니다. 두 모델 모두 Pi 5의 C 런타임에서 실행한 결과입니다.

검증 실험 (학습 데이터에서 떼어 둔 300행, 정답 수)

05학습 데이터 예시

06알아둘 점

  • 학습 데이터에 추론 한 줄이 꼭 필요했습니다

    엔진은 도구를 호출하기 전에 항상 짧은 추론(<think>)을 먼저 씁니다. 처음에는 학습 데이터에 이 부분이 없어서, 학습 환경에서는 24/24를 맞히던 모델이 엔진에서는 11/24로 떨어졌습니다. 추론 칸에 라벨을 넣자 해결됐습니다.

  • 남은 약점은 위치 자르기입니다

    유형은 거의 맞히지만(한국어 신고 24건 중 21건), 위치를 넓게 자르는 경우가 많습니다. 예: “시청 사거리 신호등이랑”, “대촌동 변압기 소음 민원 현장 확인”. 학습 데이터의 위치 규칙을 보강할 계획입니다.

  • 서버에는 한글을 UTF-8 그대로 보내야 합니다

    Needle C 서버는 JSON의 \uXXXX 이스케이프를 풀지 못해, “남산동”이 “ub0a8uc0b0ub3d9”로 들어갑니다. Python json.dumps 기본값이 이 방식이라 처음 측정에서 v2가 4/32로 나왔습니다. ensure_ascii=False로 보내면 정상입니다.

  • 평가셋이 아직 작습니다

    32문장이라 19/32(59%)는 표본 오차를 감안하면 대략 40~75% 범위입니다. 대회 자료로 쓰려면 100~200문장으로 늘려야 합니다.
